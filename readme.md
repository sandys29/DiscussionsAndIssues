## Prerequisites

Before running the notebooks in this repository, please ensure the following:

- **Dataset**  
  Load the required dataset as instructed in the notebooks.

- **GPU Access**  
  A GPU is required to efficiently run RoBERTa and CodeBERT classifiers.

- **Access Tokens and API Keys**  
  The following credentials are necessary:
  - GitHub Access Token  
  - Hugging Face Access Token  
  - OpenAI API Key

  > ⚠️ Replace the placeholder values with your actual credentials in the respective notebooks.  
  > Do **not** commit these tokens or keys to the repository.
